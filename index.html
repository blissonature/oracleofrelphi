You do not have to know the system before you enter it.

Relphi has beginner rooms. Learn the marks first, then the sky grammar, then practice with live tools.

  1. Learn the marks. Practice signs, planets, aspects, letters, and basic symbolic vocabulary.
  2. Learn the sky grammar. Build familiarity with houses, signs, planets, and how they speak together.
  3. Practice with cards. Draw, search, choose a sense, and see how ingredients become language.
  4. Return daily. Let the hour, Moon, and local sky keep the system alive.
