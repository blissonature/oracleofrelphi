# Relationship color hints

This branch makes the Sky Chart aspect-color language visible in both places where a reader needs it:

- each Exact Relationships row receives a small colored line sample;
- the chart aspect key receives the same miniature line samples;
- color and dash pattern both remain available, so the cue is not color-only;
- minor harmonic aspects receive restrained family colors while the established major-aspect palette remains unchanged.

Manual QA target: desktop and physical iPhone Sky Chart relationship list.
